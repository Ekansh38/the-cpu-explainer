title: 3 states

[frame 1]
All three wires are off. Read as binary that's 000, which is 0.

[frame 2]
The rightmost wire turns on, giving 001, which is 1.

[frame 3]
010, which is 2.

[frame 4]
011, which is 3.

[frame 5]
100, which is 4.

[frame 6]
101, which is 5.

[frame 7]
110, which is 6.

[frame 8]
All three wires are on, giving 111, which is 7. Three wires can count from 0 all the way to 7.
