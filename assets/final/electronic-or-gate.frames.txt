title: electronic or gate

[frame 1]
`input 1` & `input 2` are both open, so neither electromagnet is powered and neither metal arms is
down causing both switches in the main loop to stay open. That is why the bulb is off.

[frame 2]
`input 1` is closed, so its electromagnet starts to pull the first arm. `input 2` is still open, and the first metal arm hasn't been pulled down, so the main loop is still broken. That is why the bulb is off.

[frame 3]
`input 1` is closed, and the electromagnet has pulled the first arm down. `input 2` is still open,
but the main loop is now completed. That is why the bulb is on.

[frame 4]
`input 1` is closed, and the electromagnet has pulled the first arm down. `input 2` is closed and the second electromagnet has started to pull the metal arm down, the main loop is still completed from the first arm. That is why the bulb is on.


[frame 5]
`input 1` is closed, and the electromagnet has pulled the first arm down. `input 2` is closed, and the second electromagnet has pulled the second metal arm down, the main loop is completed from the both arms. That is why the bulb is on.

[frame 6]
`input 1` is open, and the electromagnet has started to release the first metal arm. But the arm is still touching the switch. `input 2` is still closed. The main loop is still completed, so the bulb is still on.

[frame 7]
`input 1` is open, and the electromagnet has released the first metal arm. `input 2` is still closed. The main loop is still completed, so the bulb is still on.

[frame 8]
`input 1` is open, and the electromagnet has released the first metal arm. `input 2` is now open, and the electromagnet has started to release the second metal arm. But the arm is still touching the switch. The main loop is still completed, so the bulb is still on.
