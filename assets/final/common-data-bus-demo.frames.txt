title: common data bus demo

[frame 1]
All of the control wires of both registers are all off. So the bus and the inputs and outputs of both registers are `Z`: disconnected. Register `A` has 53 stored inside of it, and register `B` has 0 stored in it.

[frame 2]
The `OUT` control signal of register `A` is on. So it is outputting 53 onto the bus, and the input of itself and register `B` because those are both connected to the bus. The output of register `B` is shown as `Z` because it register `B` is not driving the bus, even though those output wires are 53, they aren't driving 53. Register `A` has 53 stored inside of it, and register `B` still has 0 stored in it.

[frame 3]
The `OUT` control signal of register `A` is on. So it is outputting 53 onto the bus, and the input of itself and register `B` because those are both connected to the bus. Register `B`'s `WRITE` control signal is on, thus storing the value on the bus inside, in this case 53. The output of register `B` is still shown as `Z`. Register `A` has 53 stored inside of it, and register `B` now has 53 stored in it.

[frame 4]
The `OUT` control signal of register `A` is on. So it is outputting 53 onto the bus, and the input of itself and register `B` because those are both connected to the bus. Register `B`'s `WRITE` control signal is now off. The output of register `B` is still shown as `Z`. Register `A` has 53 stored inside of it, and register `B` still has 53 stored in it.

[frame 5]
All of the control signals of both registers are all off again. But now register `B` also has 53 stored in it!
