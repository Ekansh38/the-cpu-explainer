title: dog washer v2

[frame 1]
All four inputs are off. `MUDDY OR STINKY` is 0, so the first `AND` is 0, and the final output is 0. Don't wash.

[frame 2]
`MUDDY` turns on, so `MUDDY OR STINKY` is now 1. But `OLD_WASH` is off, so the `AND` with it is 0, and the output stays 0.

[frame 3]
`OLD_WASH` turns on too. Now `(MUDDY OR STINKY) AND OLD_WASH` is 1, and since `RAIN_SOON` is off the `NOT` gives a 1, so the final `AND` is 1. Wash the dog.

[frame 4]
`RAIN_SOON` turns on. The `NOT` flips it to 0, so the final `AND` drops to 0. Don't wash, it's about to rain.

[frame 5]
`MUDDY` turns off and `STINKY` turns on. The `OR` is still 1, but `RAIN_SOON` is still on, so the output stays 0.

[frame 6]
`RAIN_SOON` turns off. The `NOT` gives a 1 again, and with `STINKY` and `OLD_WASH` on, the output is 1. Wash the dog.

[frame 7]
`MUDDY` turns back on, so both `OR` inputs are on. Nothing else changes, the output stays 1.

[frame 8]
`RAIN_SOON` turns on one more time. The `NOT` makes it 0, so no matter how muddy and stinky the dog is, the output is 0. Don't wash before the rain.
